# Breast Cancer Data Analysis Using Python

## 📌 Project Overview

This project focuses on analyzing a Breast Cancer dataset using Python. It includes data cleaning, exploratory data analysis (EDA), and data visualization to identify useful patterns and insights from the data.

## 🎯 Objectives

* Clean and prepare the dataset
* Handle missing and unnecessary values
* Perform exploratory data analysis
* Analyze important features
* Create meaningful visualizations
* Generate useful insights from the dataset

## 🛠️ Tools & Technologies

* Python
* Pandas
* NumPy
* Matplotlib
* Seaborn
* Jupyter Notebook

## 📊 Dataset

The dataset contains diagnostic information related to breast cancer cases.

* **Rows:** 569
* **Columns:** 32

## 🔍 Project Workflow

### 1. Data Understanding

* Loaded the dataset using Pandas
* Checked rows and columns
* Checked data types
* Generated descriptive statistics

### 2. Data Cleaning

* Checked missing values
* Identified unnecessary columns
* Checked duplicate records
* Prepared the dataset for analysis

### 3. Exploratory Data Analysis

Analyzed:

* Cancer diagnosis distribution
* Feature distributions
* Relationships between variables
* Statistical patterns in the dataset

### 4. Data Visualization

Created different visualizations using Matplotlib and Seaborn to understand patterns and relationships in the dataset.
